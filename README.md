# ThreeTier_adar_cluade_agent_eks_aws

A three-tier web application deployed on Amazon EKS.

## Components
- **Frontend:** static web page served by NGINX
- **Backend:** Node.js (Express) REST API
- **Database:** MongoDB

## Built with
- Terraform (AWS: VPC, IAM, EKS)
- Kubernetes and NGINX Ingress
- Docker and Amazon ECR
- Azure DevOps Pipelines (CI/CD)
